# Novely — cofre do projeto

App para **ler, escrever, organizar e publicar webnovels enormes** (estilo manhwa/light novel), em português do Brasil.
Duas versões que dividem a mesma nuvem (Firebase):

- **Celular**: Android, Kotlin + Jetpack Compose → [[Android - Visão geral]]
- **PC**: site em JavaScript puro (sem framework), PWA no GitHub Pages → [[PC - Visão geral]]

Repositório: `huryelprofissional-design/novel-app` (branch `main`).
Site: https://huryelprofissional-design.github.io/novel-app/
APK: publicado a cada push em *Releases* como `build-N` / `novely.apk`.
